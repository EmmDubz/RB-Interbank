RB Interbank

A free clearing-plus-directory rail. Customers search a Minecraft name or ticker, see every matching account across member banks, and click one. Cash moves firm-to-firm through the DemocracyCraft Economy API. No prefunded Qash settlement account.

For customers

In the bank Discord app: Transfer → Interbank. Type MDBZ, DRB:MDBZ, or a player name. Pick the row. Confirm. The destination bank only credits after real RMD arrives.

For bank developers

Install the Python package, implement three functions, mount one HTTP route on the aiohttp server you already run. Qash can stay as the dual rail for banks that are not on RB yet.

How a bank joins

You receive a settings pack

  1. Bank code, e.g. DRB
  2. Ticker prefix, e.g. DRB- or none
  3. Hub URL and a one-time signing secret
  4. Your public callback, e.g. /rb/v1

You already have the rest

  1. In-game firm name (DRB, VDRB)
  2. A BUSINESS Treasury key — never sent to Inov8
  3. The same Discord transfer UI, plus an Interbank button

Security model

  • No customer balances on this host. Ledgers stay in each bank’s database.
  • No DemocracyCraft API keys on this host. Firm tokens never leave the bank server. The hub cannot spend RMD.
  • Signing secrets are shown once. The hub stores a verifier, not a reusable plaintext key in git or the website.
  • Public DNS, private origin. inov8.redmontgroup.org and interbank.redmontgroup.org via Cloudflare Tunnel. The Tailscale IP is not published.
